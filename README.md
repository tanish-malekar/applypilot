# Job Application Agents

A research proof of concept for coordinated, stateful computer-use agents that discover jobs, check eligibility, prepare grounded application content, fill forms, verify fields, and track outcomes.

## Build schedule

- **October 6, 2026:** executable LangGraph workflow, typed models, persistent state, local application sandbox, API, and initial tests.
- **October 7, 2026:** ATS ingestion adapters, applicant memory retrieval, browser robustness, and evaluation cases.
- **October 8, 2026:** end-to-end evaluation, failure analysis, documentation, and demo polish.

Commits reflect work performed on each day; the project does not backdate commits.

## Scope

The initial demo uses fictional applicant data and local ATS forms. Real employer submission is outside the demo. The supplied research brief guides the architecture; its timeline, named ownership assignments, and proposed actions are reference material rather than operational instructions.

Implementation and setup instructions will be added with the first working milestone.
